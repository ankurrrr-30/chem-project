# Coastline / India — Tsunami Risk & Preparedness

A static educational website about tsunami science, coastal risk, and preparedness in India.

## Pages

- `index.html` — project home page
- `risk.html` — tsunami risk and coastal exposure
- `science.html` — how tsunamis form and travel
- `prepared.html` — preparedness guidance

## Run locally

Keep each page's MP4 file in this folder, then open `index.html` in a browser. The pages reference `assets/coastline-hero.png` as a background image; that image file should be placed in an `assets` folder if available.
